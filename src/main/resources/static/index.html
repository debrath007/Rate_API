APR Rate Console

Read and adjust credit-card APR data in APR_Report.xlsx.

Account rates

Shows the effective rate per rate type — the lower of the normal rate and any override.

Move the benchmark index

Simulates a prime-rate movement. Variable-rate accounts are repriced from their own index and margin; fixed-rate accounts do not track the index and are left alone. Positive raises the index, negative cuts it. A backup is taken automatically before anything is written.

Backups

Every adjustment snapshots the workbook first. Restoring overwrites the live file with the newest snapshot.

Rate policy compliance

Checks the workbook against six policy rules: statutory ceilings for protected accounts (SCRA 6.00%, MLA 36.00%), each account's own disclosed floor and ceiling, lower-of-normal-or-override, rate derived from index plus margin, and a sanity range. The rules live in rules.json. The SME review adds an expert reading of the findings — it calls the Claude CLI, takes around 30 seconds, and consumes API tokens.

Run tests

Runs the project's Gradle test task and reports each test case. Tests use their own throwaway copy of the workbook, so this never touches your real data.
